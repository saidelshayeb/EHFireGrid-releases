# EH FireGrid — Releases

Public download channel for **EH FireGrid**, an AutoCAD plugin for automatic
NFPA-13 sprinkler distribution by Engineers House (بيت المهندسين).

This repository hosts only the installer `.exe` files. The plugin itself
checks here once per AutoCAD launch for new versions; users can also grab
the latest installer directly from the [Releases](https://github.com/saidelshayeb/EHFireGrid-releases/releases) page.

## Install

1. Download the latest `EHFireGrid-Setup-X.Y.Z.exe` from [Releases](https://github.com/saidelshayeb/EHFireGrid-releases/releases).
2. Double-click to run. Accept the license, enter your name + email to start
   your free 1-year subscription.
3. Restart AutoCAD 2024 / 2025 / 2026. The **EH FireGrid** ribbon tab appears
   automatically — no `NETLOAD` required.

## Updates

The plugin polls this repository's latest release once every 24 hours and
shows a non-blocking banner when a new version is available. Click `EHFG_UPDATE`
to download and install when it suits you — never silently.
