# CPVC Pipe Fittings (Schedule 80)

For light hazard fire sprinkler systems (NFPA 13 compliant).

## Expected Files
- `Elbow_CPVC_90.rfa` - 90° CPVC elbow
- `Elbow_CPVC_45.rfa` - 45° CPVC elbow
- `Tee_CPVC.rfa` - CPVC tee
- `Coupling_CPVC.rfa` - CPVC coupling
- `Reducer_CPVC.rfa` - CPVC reducing coupling
- `Cap_CPVC.rfa` - CPVC cap
