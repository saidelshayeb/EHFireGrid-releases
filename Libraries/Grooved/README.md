# Grooved Pipe Fittings (Victaulic Style)

For roll-grooved steel pipe systems.

## Expected Files
- `Elbow_Grooved_90.rfa` - 90° grooved elbow
- `Tee_Grooved.rfa` - Grooved tee
- `Coupling_Grooved_Rigid.rfa` - Rigid grooved coupling
- `Coupling_Grooved_Flexible.rfa` - Flexible grooved coupling
- `Reducer_Grooved.rfa` - Grooved reducing coupling
