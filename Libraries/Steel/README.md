# Steel Pipe Fittings

This folder contains steel pipe fitting families for fire protection systems.

## Expected Files

| File | Description |
|------|-------------|
| `Elbow_Steel_90.rfa` | 90° steel elbow |
| `Elbow_Steel_45.rfa` | 45° steel elbow |
| `Elbow_Steel_90_Grooved.rfa` | 90° grooved steel elbow (Victaulic style) |
| `Tee_Steel.rfa` | Steel tee |
| `Tee_Steel_Grooved.rfa` | Grooved steel tee |
| `Tee_Steel_Reducing.rfa` | Reducing steel tee |
| `Union_Steel.rfa` | Steel union |
| `Coupling_Steel.rfa` | Steel coupling |
| `Coupling_Grooved.rfa` | Grooved coupling |
| `Reducer_Steel_Concentric.rfa` | Concentric reducer |
| `Reducer_Steel_Eccentric.rfa` | Eccentric reducer |
| `Cap_Steel.rfa` | Steel cap |
| `Cross_Steel.rfa` | Steel cross |

## How to Get These Files

1. **Revit Content Library**: `C:\ProgramData\Autodesk\RVT 2026\Libraries\US Imperial\Pipes\Fittings\`
2. **Victaulic**: https://www.victaulic.com/bim
3. **Anvil International**: https://www.anvilintl.com/en/resources/bim-revit-families
4. **Create your own**: Use Revit Family Editor

## Notes

- Files should be imperial units for US projects
- Ensure connectors are properly configured
- Test with Auto Route before distribution
